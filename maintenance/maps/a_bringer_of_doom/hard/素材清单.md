## 后续维护

从项目根目录使用现有 Python 环境运行：

```powershell
python tools/assets/imports/prepare_profile_assets.py --profile a_bringer_of_doom/hard --reuse
```

命令默认暂存资产与配置。核对报告中每层状态及叠图后，使用同一命令加 `--publish` 发布已通过布局。源图、底图或标定代码指纹变化会重新标定；`--reuse` 不能跳过几何校验。实际原图和底图必须保留，不能只更新哈希来消除报错。

读取 `python -m src --check` 的 `errors` 和 `pending_scales`。`resource_layouts` 表示素材检查通过数，`layouts` 表示全部楼层尺度就绪的布局数，`partial_layouts` 表示部分楼层就绪的布局数，`fixed_candidates` 表示有效楼层候选数；资源完整不等于游戏内对齐。正式发行验收仍要求尺度就绪，当前没有构建新的 EXE。
